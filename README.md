## ⚡ 10-Second Quickstart (Zero Install)

Run the autonomous scope auditor directly in your project root using NPX:

```bash
npx scopelock-audit
```

Or run directly in any Git repository to scan staged/uncommitted files:

```bash
npx scopelock-audit --scan
```

### 📥 What It Does:
1. **Scans Git Diff & Source Code:** Automatically identifies unbilled feature requests, out-of-scope architectural refactors, and creep keywords (`"just quickly add"`, `"can you also support"`, `"should only take 5 mins"`).
2. **Calculates Financial Bleed:** Converts extra developer hours into dollar variance at standard commercial rates ($125/hr default).
3. **Generates Binding UCC § 2-209 Change Orders:** Produces court-admissible commercial change orders with unilateral stop-work protection clauses before unbilled code is delivered.

## 🛡️ Git Pre-Commit Hook (Automated Scope Freeze)

Freeze scope creeps before code can even be committed to GitHub:

```bash

```

This installs `.git/hooks/pre-commit` in your repository. When engineers try to commit files exceeding planned scope without an attached change order, the commit is safely paused.
